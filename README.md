# DriftOS

web os. runs in browser. that's it.

started this bc I got tired of everyone saying "just use React" for everything.
You don't need React to move a div around. You need mousedown, mousemove, and
about 40 lines of code. So I built it. And then I kept adding stuff.

![boot](screenshots/boot.png)

it's not done. it's not close to done. but it boots and you can drag windows
around and it looks decent so I'm putting it out there.

## running it

open the folder in vs code, install the Live Server extension, right click
index.html, hit "open with live server". that's what I do.

any static server works tho. npx serve . if you have node. python -m http.server
if you have python. no build step so it doesn't matter.
